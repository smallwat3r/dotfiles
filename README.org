* smallwat3r's dotfiles

Personal dotfiles managed with [[https://www.gnu.org/software/stow/][GNU Stow]].

Feel free to reuse any part of this repository, but note that it is tailored to my own workflow and updated frequently. Back up your existing setup before using the provided Makefile.

** Requirements

- [[https://www.gnu.org/software/stow/][GNU Stow]]

** Installation

Clone into your home directory:

#+begin_src shell
git clone https://github.com/smallwat3r/dotfiles.git ~/dotfiles
#+end_src

On a fresh Fedora install, provision everything in one go. This enables the
third-party repositories, installs the packages listed in ~packages.dnf.txt~ and
~packages.flatpak.txt~, enables the system services they need, stows the
dotfiles and sets up the Emacs config, claude-airlock and firefox-sway (see below). It is safe to
re-run.

#+begin_src shell
cd ~/dotfiles && make bootstrap
#+end_src

On an already provisioned machine, just stow the dotfiles (user configs to
~$HOME~, system configs to ~/~ with sudo):

#+begin_src shell
cd ~/dotfiles && make stow
#+end_src

Other available commands:

#+begin_src shell
make unstow     # remove all symlinks
make dry-run    # preview changes without modifying the filesystem
make help       # list available commands
#+end_src

** Structure

| Directory | Description                                              |
|-----------+----------------------------------------------------------|
| ~home~    | User configs, stowed to ~$HOME~ (zsh, git, sway, etc)    |
| ~root~    | System configs, stowed to ~/~ with sudo (udev rules, etc) |

These dotfiles target Fedora with sway. Debian is also supported: ~make
bootstrap~ detects it and installs ~packages.apt.txt~ in place of
~packages.dnf.txt~, builds what Debian does not package, and registers a "Sway
(dotfiles)" login session that loads ~environment.d~ (LightDM does not). The
macOS configuration was retired, it is preserved at the ~macos-last~ git tag.

** Emacs

Emacs configuration is managed in a [[https://github.com/smallwat3r/emacs][separate repository]]. ~make bootstrap~
sets it up, to do it by hand:

#+begin_src shell
git clone https://github.com/smallwat3r/emacs.git ~/.config/smallwat3r-emacs
ln -s ~/.config/smallwat3r-emacs ~/.emacs.d
#+end_src

** Claude airlock

Claude Code runs in a Docker sandbox from [[https://github.com/smallwat3r/claude-airlock][claude-airlock]], used by the Emacs
config. Its ~bin/~ (~claude-airlock~, ~claude-statusline~) is on the ~PATH~. ~make
bootstrap~ sets it up, to do it by hand:

#+begin_src shell
git clone https://github.com/smallwat3r/claude-airlock.git ~/code/claude-airlock
#+end_src

Sessions run under [[https://gvisor.dev][gVisor]] by default (~CLAUDE_AIRLOCK_RUNTIME=runsc-hostnet~ in
~environment.d/claude-airlock.conf~ and ~.zshenv~). This needs ~runsc~ installed and
registered with Docker under that name, see ~docs/sandbox.md~ in claude-airlock.
~CLAUDE_AIRLOCK_RUNTIME= claude-airlock~ runs one session under Docker's own runtime.

gVisor is not packaged for Fedora and ~make bootstrap~ does not install it. Install the
latest release by hand (x86_64 and aarch64 only), ~runsc~ and its ~gvisor-bin/~ directory
have to stay next to each other:

#+begin_src shell
(
  set -e
  cd "$(mktemp -d)"
  URL=https://storage.googleapis.com/gvisor/releases/release/latest/$(uname -m)
  curl -fsSLO "$URL/gvisor.tar.zstd" -O "$URL/gvisor.tar.zstd.sha512"
  sha512sum -c gvisor.tar.zstd.sha512
  sudo tar --zstd --no-same-owner -xf gvisor.tar.zstd -C /usr/local/bin
)
#+end_src

Then register the runtime in ~/etc/docker/daemon.json~ with the two arguments the sandbox
needs, and restart Docker (this stops the running containers):

#+begin_src shell
sudo /usr/local/bin/runsc install --runtime runsc-hostnet -- --network=host --host-uds=open
sudo systemctl restart docker
docker run --rm --runtime=runsc-hostnet hello-world
#+end_src

On Debian, gVisor's own apt repository provides a ~runsc~ package (see the [[https://gvisor.dev/docs/user_guide/install/][install guide]]),
installed in ~/usr/bin~, the registration step is the same with that path. To update,
run the first block again.

** Firefox

Firefox is stripped down for sway by [[https://github.com/smallwat3r/firefox-sway][firefox-sway]], which also provides the
~ff-launcher-*~ scripts bound in the sway config. ~make bootstrap~ sets it up, to
do it by hand:

#+begin_src shell
git clone https://github.com/smallwat3r/firefox-sway.git ~/code/firefox-sway
make -C ~/code/firefox-sway install
#+end_src
